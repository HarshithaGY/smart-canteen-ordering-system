# Smart Canteen Ordering System

A web-based Smart Canteen Ordering System developed to make food ordering and order management easier for students and canteen administrators.

## Features

- User registration and login
- Browse available food items
- Add items to cart
- Place food orders
- View order history
- Track order status
- User profile management
- Admin login
- Admin food item management
- Admin order management
- Admin user management

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- phpMyAdmin
- XAMPP

## Project Setup

1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from XAMPP.
4. Open the project through localhost.
5. The application creates and initializes the required database tables automatically.

## Project Status

Academic project developed for learning and practical application of web development and database concepts.
